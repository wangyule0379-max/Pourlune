# Pourlune 视觉、动效与 Flutter 资源交付规格

## 设计基准

保持已确认的明亮天蓝背景、厚实针织三维造型与浅色透光液体。针织纹理用于场景、瓶身外套和控件外缘；液体窗口保持干净。每层液体共用平直分界，仅最上层有弯月面，玻璃高光贯穿瓶身，避免独立圆角、厚描边和投影造成积木感。

固定语义为：浅蜜桃橙配圆形、浅叶绿配三角、淡紫配菱形、浅蓝配方形。液体、目标标签和提示始终沿用同一映射；瓶套颜色不代表通关目标。形状使用清楚的深色平面标记，空瓶保留透明感，不与浅蓝液体混淆。

## 字体与布局

UI 建议采用 Nunito 或清晰圆润的 Sans 字体，正文保持易读，按钮采用适度字重；这是字体方案，不表示该字体已嵌入概念图。关键文字和图标采用深色，装饰色不承担唯一指令。

交互控件和瓶子点击区域建议至少 48 逻辑像素。常规六瓶为 3+3，额外瓶状态为 4+3，后一行居中；同一棋盘内两行瓶子保持同尺寸；加瓶后如需缩放，七瓶必须统一缩放。小屏优先缩减布景、顶部装饰和非必要留白，不挤压棋盘、标签或底部操作区。

## 资源拆分

针织房间、家具、瓶套和柔和阴影交付为预渲染静态资源，保留透明背景、统一光向及明确裁切边界；同时提供适配清晰度的分辨率版本。液体、液面、形状、选中反馈和水流作为独立动态层，不能烘焙进瓶身图。Flutter 建议局部绘制与局部重绘，背景复用缓存，不把实时三维、全屏折射或流体模拟作为前提。

## 动效与模型一致性

一次倾倒建议约 0.7–1.0 秒，依次呈现轻抬、倾斜、连续液流和回位。液面随重力保持水平，源瓶减少量与接收瓶增加量一致。Reduced motion 开启后用短促液位变化和高亮代替大幅移动，保留操作结果。

合法移动原子提交源瓶、目标瓶及撤销记录；动画只表现同一变更的前后状态，不负责再次扣加液体。动画期间不接收第二次棋盘操作；暂停、后台或中断后对齐已提交状态。保存失败保留内存棋盘并提示重试，不能以动画结束宣称保存成功。

## 设置与交付边界

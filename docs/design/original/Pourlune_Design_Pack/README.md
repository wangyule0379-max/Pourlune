# Pourlune · Design handoff

## 内容

- Pourlune_Product_Design.pdf：全套页面与中文产品说明。
- PRD.md：完整可检索产品规则、页面契约、保存策略、广告状态及验收案例。
- UI_copy.csv：178 条英文 UI 文案，UTF-8 BOM，按 P01–P21 编号。
- screen_catalog.json：7组视觉板与21个页面的索引。
- Visual_and_Motion_Spec.md：视觉、动效、资源拆分摘要。
- Level12_Example_Validated.json：第12关示例的15步有效解及逐步盘面。
- boards/：7张最终视觉板，加用户已确认的风格参考图。

## 使用顺序

先看 PDF 中的全套页面，再按页面编号阅读 PRD 与文案表。图中第12关、3/5拼片、2026-10-21日期均为示例，不应在应用中写死。源图是风格与布局参考，具体的状态判定、按钮文案、目标标签、等尺寸瓶子布局以规格为准。

主线首版规划60关，三章分别为Color Studio、Garden Nook、Seaside Corner。本次为产品设计，未开发App，未完成60关生产题库、分层资源切图或真机性能验证。

生成日期：2026-10-21。方案名称：Pourlune。

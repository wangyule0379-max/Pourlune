# 组件、布局与复用说明

基准390×844 CSS逻辑像素；窄屏320×700；设备密度1的截图。图册不是 Flutter 或原生 App。

- 背景延续原天蓝目标 #82DFF1；正文深蓝 #061B78，奶油针织面板、青柠绿色针织主按钮。已从原图裁切纹理和组件，不重新设计色系。
- 原型通过 CSS `local()` 引用本机已安装的 Arial Rounded MT Bold；未确认分发授权的 `assets/rounded.ttf` 不纳入仓库，素材提取脚本也不再复制系统字体。没有该字体时回退到 Arial / sans-serif，可能改变字形和换行；本轮精确视觉验收以当前 Mac 环境为范围，截图保留当时外观。规格推荐的 Nunito 仍是正式客户端字体方案。正文16、二级标题26.4、行高约1.3–1.45；按钮随字号增长并换行。
- 基准页左右18、顶部50、底部34；窄屏左右12、顶部28、底部24。内容间隔16（窄屏10）。面板内边距20×17、圆角28、奶油边5；按钮最小52高、常规圆角24、按钮间距10。Back可点击盒48×48。
- 模态背景 inert 且 aria-hidden，面板 role=dialog / aria-modal；长正文和按钮在内部滚动。200%样例采用可滚动面板，提供顶部及底部截图。不是正式焦点循环或 VoiceOver / TalkBack 认证。
- 六瓶3+3；七瓶4+3，末排justify-center。七瓶每一项共享 `width:calc((100% - 24px)/4)`，默认图盒155高，窄屏122，窄屏200%图盒110；四个目标和三个缓冲同尺寸。实测尺寸见 verification.json。触点宽在320屏下约66，均大于48。
- 目标固定橙●、绿▲、紫◆、蓝■。目标装饰与标签一致；缓冲使用中性奶油瓶、无液层或形状，下面“—”仅作中性缓冲标识。四条容量刻度在瓶体玻璃边，不插入液层空气缝隙。教学上橙2单位、下蓝2单位，各段只一个形状；刻度提供4单位基准。
- 大字号保持正文与按钮文本随200%增长；七瓶样例收起非必要重开持有说明，保留“Extra bottle added”。辅助按钮重排为Undo/Hint并列＋Bottle added整行，可随页面滚动，不覆盖瓶子。提供顶部／底部证据。正式 App 必须在平台字体策略下复验，不能据此宣称系统所有字号均已通过。弹窗采用内部滚动、设置采用页面滚动。
- 开启 stronger contrast 时，正文／控件边线加深，瓶体局部对比增加13%，浅液体不改成整瓶浓色。保留形状辨认。尚未测每个液色／文字组合的4.5:1，不能宣称无障碍全通过。
- 原动效不重做；图册静态，遵从 prefers-reduced-motion 无动画。原生倒液0.7–1.0秒、减少动态120–180ms是原稿目标，未在本轮验证。

## 原框架与自适应研究的区别

`tutorial-fidelity`保留原P04布局、手势、箭头、月亮、花卉和控件，仅修目标／缓冲瓶装饰与容量刻度；静态390×844原框架，另用`tutorial`展示可重排组件。`seven-fidelity`保留原P18背景与控件，同一84×177单瓶图盒分4+3；另用`seven`展示真实宽度／大字号重排。原框架中的既有按钮为视觉证据，自适应原型中的按钮才是可点击状态跳转，两者都不是完整游戏。

R1模态背景已经使用当前上下文的D06组件（inert），因此旧每日／重玩／七瓶与未保存或pending状态会显示正确身份和瓶数；不再固定贴Level12原图。正式客户端仍需真实液体分层，不能把当前静态单瓶参考当作最终动态资源。最终美术分层与动态液体仍待后续。

## R1 最小原型上下文与素材重拆

`puzzle`仅保存显示所需的mode/level/day、layout/guided、added/pending/unsaved/cooldown及临时反馈。`navigate`把页面内返回和明确新建关卡区分，辅助不会重建默认实例；`resetFixture`只用于新题入口或评审新样例。没有引入存档库、全局状态框架或真实引擎。

未保存／待奖励横幅由独立标记生成，Undo/Hint/Resume只改变视图，不消费标记；明确保存成功或奖励写入成功分别清对应标记。Restart保留已授予瓶和身份；Skip只把guided关掉。

R05：原等分裁切跨过瓶体轮廓。`tools/split-bottles.cjs`根据同一原片非重叠区间重新提取，移回原396×793透明画布，保留竖向尺度、容量刻度与原RGBA内容。`assets/bottle-crops.json`为精确裁切配方；没有重新生成整套瓶体。D08的按钮／图盒CSS和D09布局不变。

## R06 状态横幅按钮规则

状态横幅的`.row`允许flex换行，正文`flex:1 1 9em;min-width:0`，按钮`flex:0 0 auto`、`min-width:min-content`、`max-width:100%`，左右padding12px，最小高度48px，字体保持继承的1em。只在这些按钮上使用`overflow-wrap:normal;word-break:normal`，避免全局anywhere拆开Retry。文字区不足时按钮另起一行、靠右，不降低用户字号，不隐藏文本或辅助入口。

320宽200%增强对比实测：Retry 101.86×50.59，Retry save 171.81×50.59，Retry reward 205.36×50.59 CSS px，字体均28.16px。当前浏览器其他组合与七瓶尺寸记录见`revision-r06/after/results.json`；这些不是原生平台可访问性认证。

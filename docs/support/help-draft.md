# Pourlune help — DRAFT, not deployed

Match each full target bottle to its fixed color tag and leave every buffer empty. Target tags do not prevent temporary use for another color. Tap a bottle, then a legal destination; a move pours the continuous top color that fits. Hint, Undo and Restart are free. Hints search your current board and may time out without proving the puzzle impossible.

Every accepted action saves locally. If saving fails, keep the app open and use Retry. Some changes may exist only in memory until Retry succeeds. Stay cancels queued navigation. Core play does not need an internet connection. Main and daily puzzles have separate active slots; replacing one requires confirmation. Daily dates use the device's local calendar.

Extra Bottle is hidden on main levels1–3 and available from main4 and daily puzzles. Its explanation precedes the explicit Watch button. Ads can be unavailable, loading, cooling down or prohibited by privacy eligibility. Free tools remain available. One bottle can be earned per puzzle instance; Undo and Restart retain it. Closing alone earns nothing. Retry a received-but-unsaved confirmation before closing the app. A saved reward for an earlier puzzle requires explicit restoration and replaces only that slot. An interrupted request without a saved confirmation cannot be verified by the SDK.

Settings includes accessibility preferences, a practice board, privacy choices and progress reset. Support website, policy and feedback email are build configuration entries. Their approved destinations have not been handed over; do not substitute an example address or submit personal data to a placeholder. Contact/support-response procedures and recovery limitations need owner approval before this page is published.

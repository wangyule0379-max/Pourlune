## 6. 阶段完成标准

1. **准备与探针阶段**：协作约定、版本管理和工具链就绪；规则样本可验证；真实瓶体的绘制、提示与保存恢复风险得到实际检查。
2. **可玩闭环阶段**：能进入一关、倒水、撤销、提示、保存、通关、领取一次收藏并恢复；先使用可控的广告测试替身，不冒充真实 SDK 联调完成。
3. **内容与服务集成阶段**：UI 增量通过、题库和收藏资源齐备，真实 SDK 使用测试广告验证，离线与异常恢复通过。
4. **发布验收阶段**：按 AC 矩阵执行，完成设备、隐私、签名与发布资料核验，列明实际证据和剩余问题。

当前应优先推进第一阶段，并继续独立完成 UI 增量验收。文档准备完成不代表开发已经启动或所有开工条件已经通过。

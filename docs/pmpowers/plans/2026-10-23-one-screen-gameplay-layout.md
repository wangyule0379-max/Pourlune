# 游戏与结算页一屏布局修正（LY01–LY06）

日期：2026-10-23。用户实图指出 Level 10 六瓶页面上下留白过多，必须滑动才发现底部按钮，并要求游戏与每关完成页完整展示主要内容。本任务优先于 BR07 素材收尾；原开发先保存 BR07 安全检查点，再实施本任务。架构独立验收，不代写实现。

## 已定位的问题

- `game_screen.dart` 将包括棋盘和完成页在内的内容放入整页 SingleChildScrollView，棋盘无法获得有效可用高度。
- `flame_board/geometry.dart` 的 BoardLayout 只按宽度计算高度，独立的动画留白、行距和上下标签使棋盘过高。
- `collection_pages.dart` 的 CompletionPage 复用完整 BoardView，静态结算预览仍占用倒水所需空间，操作按钮进一步落到首屏外。
- 旧 FB/T 验收结论保留其已验证范围；本次新增 LY-R01/P2 布局缺陷，不以旧通过代替新验收。

## 交付和验收

### LY01 有界页面布局
仅调整游戏、完成与关联拼片奖励页面。SafeArea 内按可用高度分配顶部信息、棋盘/静态预览和操作区。正常字号下全部瓶子、对应标签/容量、当前可用 Extra bottle、Undo/Hint/Restart 与核心关卡信息直接可见、可触达，不需先滑动。列表页面继续使用合适的滚动布局，不全局移除滚动。压缩装饰与冗余间距，不通过整体缩放导致文字或触控区域难用。

### LY02 棋盘几何与运动
4/5/6/7 瓶、跨行倒水、七瓶同尺寸；标签与所属瓶视觉关系清楚，命中区域与绘制对应，不重叠误触。按可用高度适配形状、行距与路径；验证运动全过程不越过可视边界、不覆盖顶部/底部控件，不能只删 gutter 导致飞行被裁切。保留 FS-M01 数字与液面同步、视觉量守恒、完整动作立即落盘与过期 token 丢弃，不修改规则/控制器奖励权威。

### LY03 结算与拼片页面
使用合适的只读紧凑棋盘预览，不保留交互棋盘飞行留白。主线普通通关、拼片、章节、最终关、每日、重玩各分支及关联 RewardPage 的当前主要动作（如 Next/View patch/Daily/Replay/Home）首屏清楚可见。不得隐藏保存失败、未持久化回执或绕过导航门控。静态预览不启动新游戏实例或写奖励。

### LY04 适配与辅助功能
覆盖 iOS/Android 安全区、常见小屏和高屏，明确报告实际 viewport/textScale。至少检查 375×667、390×844、430×932、Android 360×640；兼查 320×568 的布局边界，不默默改最低支持范围。正常 1.0 与 1.3 字号核心流程一屏；1.5/2.0 或平台大字号优先可读性，可让说明区受控滚动，但主要操作持续可见，不裁掉文本或按钮。触控最小区域保留 48 逻辑像素，焦点/语义与实际区域一致。教程、无可行步、保存错误、提示搜索等临时信息不得挤没必要操作。

### LY05 有效验证
新增聚焦布局测试检验真实可视边界与 hitTestable，不只验证 finder 存在；默认未滚动时就能操作。测 4–7 瓶、结算各分支、字号、安全区、过渡和关键运动帧。按风险复跑容量同步、连点/返回、失败保存与恢复相关用例，不重复无关全量套件。双端独立 QA 正常入口实际操作游戏→通关/拼片→下一关，实际保存恢复与转场回归；不足条件明确记录，不能以作者自查替代架构独立验收或以 debug 模拟器证明真机性能。

### LY06 交付与候选
交付 `docs/development/deliveries/one-screen-layout.md`，证据 `docs/development/evidence/one-screen-layout/`；包含文件清单、逐项证据、可复跑命令、实际设备/窗口、剩余局限及明确 CLI 释放。架构报告 `docs/development/review/one-screen-layout-acceptance.md`。独立验收通过后仅提交本任务已验范围并推送，检查精确实现 CI。BR07 未验素材不得夹带。旧 build6 保留冻结；新布局通过后再安排新版本候选与独立包验证，旧包不自动代表新布局通过。

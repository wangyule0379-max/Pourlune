## 首轮约五分钟

- 打开并玩一关，确认棋盘及免费Hint、Undo、Restart能直接使用；遇到七瓶及过关页时，留意主要按钮是否不用滑动即可看到。
- 做几步后退出App，从多任务界面结束，再重新打开，核对关卡和棋盘恢复；不要卸载或使用Reset Progress来测试恢复。
- 安装完成后临时关闭网络，再玩一关并重新打开，确认离线玩法与存档正常，结束后恢复网络。
- 听一次音乐/音效并切换设置；记录声音、触觉或字体异常。性能/读屏尚无本人真机结果，不预写通过。

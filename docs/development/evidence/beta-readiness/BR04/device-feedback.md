# 用户手机最小试玩与反馈表（分发后才使用）

当前没有分发或生产运行授权，本表不是已执行结果。测试者不需要开发者模式、USB调试、导出数据库、刷机、清档或装描述文件。密码、验证码、私钥、IMEI/UDID、私人照片和无关账号资料不收集。

最小顺序：从正式TestFlight/Play入口确认构建并安装→保持隐私默认off、广告关闭→Start并实际倒一次合法水/试一次非法动作→Hint/Undo/Restart→离开并继续主线→每日进一局再返回主线→正常完成后看Next及Collection→正常退出再开检查最近已保存状态→按需切换减少动态/声音等并体验。核心离线测试只在本人手机正常断网条件下操作，先说明RC可能已有联网处理；不修改TLS/代理或要求故意耗尽空间。无权限或不方便的步骤直接填未测。

# 最终候选重建、复验与回退条件

当前0.5.0+5用于冻结工程证据；Androidunsigned及空公共目的地使它们不是最终完整提交包。保持BR01目录不变，今后创建新隔离目录。当前生产配置依旧compile-only。

|新事实／改动|需要的动作|可继承与必须重验|
|---|---|---|
|仅确定SKU/持有人联系/组/地区等控制台资料|填入已批准资料，核对与实际包/政策相符；不自动上传|不凭纯文档要求重编；需更新提交矩阵/账号记录，控制台mandatory以实际为准。|
|批准公开支持/隐私URL和邮箱|检查HTTPS内容/可达性/归属及邮箱真实收件，安全接入编译配置；当前beta_build未暴露这些参数，不能声称填文档就进入包|定向扩展既有构建门控及有效RED→GREEN，保留prod/adsdisabled/拒绝错配/日志脱敏；新包实际ServiceConfig与点击路径需复验。|
|Android选定已有授权key|仅本地解锁，核对证书/alias归属；新副本签名AAB并验证，不原位覆盖unsigned包|签名工具/配置是后续明确工作，不把当前不支持Android签名的beta_build说成一条命令完成；保护秘密不入仓库/日志。记录JAR签名和最终APK app-signing证书连续性。|
|允许生产配置实际运行并取得设备|按BR02契约实际安装/离线/隐私/升级等验证；采集off不保证无RC请求，不改TLS/网络安全策略|未授权前继续不运行。若网络条件无变化，不重复旧Firebase失败；成功/失败都保存真实终点，不以调用完成当控制台收到。|
|改Dart/原生/服务/权限/资源/SDK/配置|更新version build，严格串行noAdID、enforce-lockfile、必要format/analyze/相关自动测试；按现有README新目录构建|比较394来源/新配置散列和二进制身份；定向原生签名/嵌套ID/SDK/资源/隐私/安装复验。SDK实际变化查官方资料，不为凑指标升版本。|
|同身份正式升级|必须先有合法安装旧N、同签名连续性新N+1且数据前后可比|只存在0.5.0(5)不能凭构建旧QA编号补作升级证据；换身份、重装、清档不计。schema或数据变化须非空迁移验证。|
|只有签名或配置修订且尚未上传|新文件名/目录和hash，记录差异；最终发布构建号与控制台现有最大号核对|建议下一最终候选增号以避免混淆；若平台已接收相同版本构建号，必须按平台规则用更高构建号，不覆盖已接收包。|
|运行缺陷／安装失败|保留原安装/数据/原始证据，定向修复，兼容迁移后新构建复验|未上传则阻止提交；已分发阶段暂停新增分发或停止测试需后续授权。不能降版本覆盖、远程清档或承诺云恢复。|

最终核对顺序：来源和配置指纹→正式身份/版本/实际显示名→签名/profile或上传证书→包格式及SDK/权限/隐私manifest→全部资源/90内容→符号与二进制UUID/对应mapping→适用设备/同签名更新→公共入口/准确披露及权属→内部/外部/closed分别决定。通过后才由用户另作上传/审核/开轨道/邀请决定。

现有签名与构建命令见[validation说明](../../../../../tools/validation/README.md)，不要复制带占位密码的命令执行。符号保持本地，prod不上传；dSYM可按archive保留，AndroidR8 mapping从精确AAB提取，Dart此次未用--obfuscate/--split-debug-info，未虚构额外Dart符号文件。

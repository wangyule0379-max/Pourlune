# 全曲线阶段依赖说明（候选，实际体验待父验收）

本轮完整60关。1–4两色、5–8三色、9–20四色经逐关复核保留原字节；
21–60为五色新定义。逐关初盘、完整参考解、决策局面和两条可行续路见
`levels/main-XXX.json`，60行概览见`curve.csv`。以下数字为玩家可见的1起瓶号，
“分支步骤”从该关键局面重新计数。是路线中确实发生的依赖，不宣称所有解必需。

## 21–30：从块状剥层到中途换用途

本段保留双层／三层块，五色都参与拆解。重点由“先合一色”变成“先释放可接下一层
的入口”。例如30关的关键盘为`OOOP / GGGG / POPP / RBBB / BR / RR / 空`。
7号接P后，3号顶部P2也能合进去，露出O；此时1号因先移走P而能接O，3号因此只剩P。
另一边5号R须先并入6号，才能让4号B3接进5号；4号露R后再送6号，才出现能回收B的空4号。
两条链分别是“P入口→露O→O入口→留P目标”和“先卸R→B入口→清空4→B归位”。

若先让7号接B3，7号暂时不能接P。另一条合法路线先让4号R借5号，再把5号R2合进6号，
将5号B转回4号、6号R归5号，腾出6号后才处理P/O链。两条完整续路9／10步，
这一差值很小；它证明换序可行和入口释放条件，不能据此称为明显高难。30参考路线
6号缓冲G→R→P的三次用途在单关卡回放，仍不是所有解都必须如此的证明。

## 31–40：借目标瓶建立多段中转

本段大多有19个可见色段，混色来源更分散；这只是结构描述。35与40特别核临时目标
换用途，不能只在两只缓冲里分色。40关关键盘`BGGG / BOOO / OBPP / R / GBPP / RRR / 空`。
先以7号接3号P2后，4号R可并进6号腾空4号，才让3号B有去处；露出的O接2号O3，
再把2号B送4号，2号才空出来接1号G3。接着1号B→4号腾出1号，才能从错标签的3号
回收O4。链条具体为“卸4号R→借4号接B→3号露O→清2号→接G→清1号→回收O”。

若先让7号接G3，则先清1号B到4号，由1号临接2号O3；清2号后回收7号G，7号才重新
可接P。两路13／14步，依赖不同但没有证明强制深搜或巨大惩罚。本段是否相对21–30
真正增加玩家判断仍由父实际操作决定。

## 41–50：协调多个未完成入口

本段普通关依旧保留混色目标和中途空间再分配，不能把阶段名当难度结论。50关第5步
局面`GPP / BPGB / BOGO / GBOO / P / RRRR / 空`。7号先接4号O2，使4号露B；
1号P2可以直接接5号P，并露G。于是2号B→4号、G→1号、P→5号、B→4号，逐层清空2号。
清出的2号接G，1号随之腾空，3号的O/G交错层才有两个接收口可轮流使用。
它的具体释放条件不是“多倒几次”，而是4号先露B、1号先露G、5号有P容量三者协调。

若7号先接P，5号P可跟进而清空5号，接6号R4后腾出6号；1号G进入6号，清出的1号改接O。
这条路交换了“目标入口”和“缓冲入口”的角色，仍是16／17步可行续路，非坏选即死。
未证明该段的判断深度显著高于上一段，父体验不通过就返工具体题段。

## 51–60：较少连续块，叠加入口释放与标签回收

本段所选初盘有20个单层色段，同时保留五色拆解；不是以色段数直接评分。60关第11步
盘`GGG / ORRR / GB / PPPP / OROO / BBB / 空`。7号接2号R3后，2号露O；3号B先接6号B3，
使3号露G可接1号G3，清空1号。2号O→1号后，空2号才能接回G4，空3号接P4，再从5号
逐层回收O2/R1/O1。中途的入口由“清1→清2→清3”接力，而6号B4/7号R暂时仍占错目标，
最后必须安排标签回收，不能误把整色满瓶当作已胜。

若先让7号接3号B，3号G可先归1号；空3号接P4腾空4号，6号B3和7号B1先归4号，
释放6/7后才处理2号R和5号O/R/O。两路线11／12步。主要变化在释放顺序与末段回收，
不是已证高难或“必须看很多步”的结论。

## 测量和已知限度

相同两种有限策略，各64固定种子、120次合法动作。旧21–60的greedy为446/2560、random
为400/2560；新候选分别59/2560、75/2560。旧greedy也只有17.4%，而用户已实际轻松到28，
所以这些数只能筛明显弱题，不能预测人的挑战。循环、无合法步和预算耗尽分别保留。

`fixed-buffer-limit.json`保存全部40题的反例：另有固定两缓冲用途的合法完整解。它明确
反驳“参考解中换用途，所以所有解必需”的推断。新五色和上述局部依赖仍可能被熟练玩家
快速识别；当前是完整可玩候选，难度门槛未关闭。父须操作不同阶段的真实盘面并注明看过
答案／用过Hint；不是让用户先批准几个样题再继续开发。尚无新版本上传。

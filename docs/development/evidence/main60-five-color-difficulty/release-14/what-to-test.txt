Pourlune 0.5.0 (14)

This build updates the main campaign to a reviewed 60-level candidate. Levels 1–20 keep their existing definitions. Levels 21–60 now use five colors with seven starting bottles; one optional extra bottle remains available per level instance. Ads remain disabled.

Please try the later chapters, the fifth color and target symbols, pouring across both rows, Undo, Restart, Hint, and the five-target completion screen. Difficulty is a staged beta candidate and still needs first-play feedback.

Existing in-progress games retain their saved puzzle definition. Restarting an existing game uses that same saved definition. Newly created games use the updated catalog. Progress, earned pieces and extra-bottle entitlements should remain intact.

The daily puzzle pool and catalog are unchanged. Core gameplay remains available offline.

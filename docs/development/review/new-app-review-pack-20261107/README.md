现在不用重复登录、提供电话或操作模拟器。**最终候选确定后一次完成**：用实体iPhone（如最终仍支持iPad，也需实体iPad QA）运行该版本，记录设备/系统/构建，按脚本演示从启动到正常游玩；另实测锁屏返回、声音和进度恢复，提供原始录像与遇到的问题。设备应使用Apple此次要求的最新正式系统；不要清除日常存档来造首次启动，首次欢迎态缺证由我们安排隔离测试。若没有对应实体设备，集中说明缺哪一类，不能用模拟器替代或谎报。

# 一次完成真机录像与重点QA

## 前提

录制对象是将正式提交的准确版本，不是任意旧TestFlight包。当前22可供体验，但internal-only及测试广告配置不是正式候选已就绪的证明。最终包定下后再集中录制，避免要求用户反复录。

使用实体设备和最新正式系统；不使用模拟器、浏览器或剪辑拼接代替真实流程。记录下表，不录密码、通知内容、个人账户信息。无需创建游戏账号。不开启生产统计制造QA数据；按已核定QA隔离方式验证后台，录像中的统计选择如实保留。

## 给审核看的主片（建议3–5分钟，不是Apple时长限制）

1. 从桌面点击Pourlune启动；显示真正的首页。首次欢迎页若出现，展示条款/隐私入口与Continue；若已选择，不卸载清档强造首次启动。
2. 点击Play进入一局，演示几次合法倒水，展示目标和计步；使用Hint及Undo，再继续操作。
3. 演示Extra bottle及获奖后的新增空瓶。使用官方测试设备配置验证广告，说明其测试标识；不能把模拟奖励或测试素材宣称为商业填充。若当时没有广告，保留实际提示，不能剪成获奖。不要点击真实广告来“测试收入”。
4. 在合适的简单关完成关卡，展示结果和Next；符合频控才出现的插屏如实展示，不通过修改远程频率强制触发。
5. 回首页/Levels/Settings；展示声音、统计选择、隐私/支持入口。无账号、UGC、付费功能，不需要造相关演示。

主片尽量连续，正常等待无需剪掉。录像链接由我们整理并核验无需登录/申请权限；上传到审核附件或在Notes给出可访问链接，不冒充商店App Preview。

## 同批必须实际检查，单独记录结果

- 游戏中锁屏约15–30秒再解锁：画面继续、点击可用、背景音乐/倒水声音符合设置；再正常倒一次，不能只有静态截图。
- 切后台后返回，以及正常退出再打开：局面、步数、已获额外瓶、统计/音频选择保持；不重复发奖。
- 首页→关卡→暂停/设置→返回：过渡可见、不闪空白；弹窗X与标题不重叠，不点击穿透。
- 使用设备正常方向/安全区检查上下区域、操作栏和瓶阵；若支持旋转，实际旋转回来能用。
- 断网时核心关卡可玩，服务失败不锁住游戏；恢复网络不假称补传已验，服务端结果另由我们核对。

锁屏可能中断系统录屏：保留中断前后两段及发生时间即可；必要时用另一设备拍摄连续外观。不要把黑屏期间录制缺失当作已通过。若重现卡死，保留原片、关卡/最后操作/时间，不清档；我们负责诊断与修复。

若正式支持iPad，iPad也须做适用的真实操作QA；是否另需完整片按Apple实际反馈处理。当前ASC还开着Mac/Vision Pro供应，这些平台由我们核对范围及测试条件，不能冒称已验，也不默认让用户采购设备。

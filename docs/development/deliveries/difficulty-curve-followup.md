## 求解与试玩验收

1. 保留无额外瓶的合法参考，逐步验证守恒、容量、固定标签、缓冲瓶为空；每道新题独特性检查同时覆盖颜色/瓶位正规化与策略重复。
2. 同一求解器、状态预算和机器测结构/分支及参考路径；必要时对小样本用有明确耗尽边界的精确搜索求最短路径。预算耗尽只记timeout，不推断无解，不给非最短结果贴最短标签。
3. 比较当前12/13/21及替代样本，记录需要腾空、恢复目标错位、暂时倒入非目标色的原因；检测一步显然整理链、初始整瓶和过多等价自由动作，但不因单个指标否决所有缓和关。
4. 真实试玩以正常规则、不买瓶/不自动代玩，记录关卡版本、尝试、撤销/提示、卡点及策略复述。先盲试再看参考；只在实际完成后填写观测。当前没有这类新样本或试玩结果，DC-R01保持打开。

# B03 题库候选

60主线＋30每日，`production_candidate`。`puzzles/` 与 `catalog/` 是候选定义的权威目录；客户端副本位于 `app/assets/puzzles/`、`app/assets/catalog/`。目录为 `catalog/daily.json`，版本1、epoch 2026-01-01、daily-001至030循环。

原main-001教学夹具有意延续；main-012恢复原稿身份与原解不变；main-021新定义版本2。其余88道为指定结构与固定seed下的独立新定义，不是重命名工程夹具。正式脚本、命令和打包校验见 `tools/content/README.md`。

自动验证、90道学习点、引用来源、唯一性与限制见 `docs/development/evidence/B03/content-evaluation.md`。候选状态和自动回放通过不代表人类难度、视觉、真机表现或独立验收通过。
